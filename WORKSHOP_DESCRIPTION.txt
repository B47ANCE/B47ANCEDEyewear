[h2]Overview[/h2]
Secure compatible glasses and supported hats using common materials. This is a Lua-only mod with no Java or JAR dependency.

[h2]Features[/h2]
• Find the rare Unbreakable Eyewear Retainer in school lockers, optical-store containers and pharmacy cabinets. It cannot be crafted and loses no condition from ordinary wear or catches.
• The rare item retains the original black adjustable-cord artwork. Craftable cloth and leather retainers now have distinct inventory icons.
• Craft Cloth Eyewear Retainer or Eyewear Retainer in Tailoring, then Wear it alongside glasses. Take Off keeps the same item for reuse.
• A dedicated slot protects one compatible untied pair using the server fall setting. Both materials currently provide the same reusable protection. Monocles and hats are excluded from wearable-retainer protection.
• Crafting → Tailoring → Tie worn eyewear secures compatible vanilla glasses or a straw/summer hat. Wear the item and keep a supported material in your main inventory.
• The recipe checks eligibility, disables batch crafting and consumes one use only on a successful server-owned tie. Right-click → Tie remains available for supported modded eyewear.
• Use twine, a rubber band, dental floss, ordinary thread, sinew thread or aramid thread. One use is consumed.
• Tied items retain their original identity, condition, prescription and model. Untie restores the original name; no material is refunded.
• Untied eyewear uses individual retention profiles. Strapped protective headwear defaults to a zero fall value; loose hats retain vanilla behavior.
• Inventory inspection preserves vanilla information and displays tied attachment material and secured state. Historical finite-retainer records are labeled inactive.

[h2]Compatibility & Requirements[/h2]
Mod ID: B47ANCEDEyewear. Target: Build 42.21. Monocles cannot be tied. Existing optional Authentic Z eyewear support is retained; current in-game compatibility remains unverified.
Client requests are validated by the server. Single-player and dedicated multiplayer acceptance are pending; this build is not multiplayer-certified.

[h2]Configuration[/h2]
Server sandbox settings control new tying, the untied-eyewear fall multiplier, and the strapped-headwear fall value. Defaults preserve the previous retention behavior. Disabling new ties does not remove existing ties or prevent untying. Wearable-retainer settings separately control crafting/protection and the retained fall value (default 0); disabling preserves existing retainer items. RareRetainerLootChance defaults to 0.25% per eligible new fill, range 0–5%; zero disables new spawns. Already filled containers remain unchanged.

[h2]Known Issues[/h2]
Exact -1 durability per successful vanilla knock-off is blocked by the missing server-safe Lua hook. No durability decrement or substitute fall roll is enabled. Fitted worn models are not included; all three items have inventory icons and an invisible clothing definition.
This development build has offline source and package preflight checks only. Actual UI, combat, save/reconnect and dedicated multiplayer behavior remain unverified.
